Iot Sitting Time Tracker - Health Awareness Project

Posted by Chin Chong Yong 2026

The IoT Sitting Time Tracker is an innovative project designed to promote health awareness and encourage better posture and movement habits. Using Arduino sensors and intelligent alerting systems, this project helps users monitor their sitting time and receive timely notifications to stand up and move around.

The project was built using a modern tech stack that combines frontend and backend technologies. The React.js frontend provides an intuitive user interface for project managers, while the Spring Boot Java backend handles complex computation and data management. This full-stack approach ensures a scalable and maintainable solution.

Core Hardware Features

Presence Detection: Integration with a pressure sensor mounted under the chair to accurately detect when you are seated.

Audible Alerts: A passive buzzer that triggers a gentle chime when the session duration exceeds your predefined threshold.

Connectivity & IoT Features (Blynk Integration)
  • Real-Time Dashboard: A live widget showing your "Current Session Duration" and "Total Sitting Time Today."
  • Remote Configuration: Use a slider or numerical input widget in the Blynk app to set your Session Time Limit (e.g., 30, 45, or 60 minutes) without needing to reprogram the Arduino.
  • Daily Analytics: * Historical Charting: A SuperChart widget to visualize your sitting habits across the week.
